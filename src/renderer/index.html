Crowd Simulation

Runs a crowd-flow simulation over the same masks above and produces a density map for each time step.

Runs the layout optimizer (optimizer/): repeatedly re-simulates this venue with movable elements nudged to different positions/sizes (or removed, for movable furniture), trains a small surrogate model on those results, searches through the surrogate for a better layout, then re-verifies the winner on the real simulator before offering to load it — a real, industry-standard excess-density cost (space- and time-integrated, above a Fruin-LoS crowding threshold), not just mean density. "Training samples" is how many of those re-simulations it runs before searching — more is a more thorough search but takes proportionally longer (roughly a minute or two at the default of 100 on a modern machine). Requires a one-time Python setup — see optimizer/SETUP.md.
